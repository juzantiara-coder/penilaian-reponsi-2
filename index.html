Integrasi Google Drive / Spreadsheet

💡 Cara Menghubungkan ke Google Spreadsheet Anda:
  1. Buka Google Drive (drive.google.com), buat file Google Spreadsheet baru.
  2. Klik menu Ekstensi → Apps Script.
  3. Hapus kode bawaan di editor Apps Script, lalu klik tombol di bawah untuk menyalin kode script terbaru.
  4. Tempel kode → Simpan → Klik tombol biru Terapkan (Deploy) → Penerapan baru (New deployment).
  5. Pada ikon gerigi pilih Aplikasi Web (Web app).
  6. SANGAT PENTING: Pada kolom "Siapa yang memiliki akses" (Who has access), WAJIB pilih "Siapa saja" (Anyone) agar hasil jawaban praktikan langsung masuk tanpa terhalang izin akun!
  7. Klik Terapkan → Beri Izin Akun → Salin URL Aplikasi Web (berakhiran /exec) → Tempelkan pada kolom di bawah.
⚠️ Tips Mengatasi Error "Anda Memerlukan Akses / Access Denied" dari Google:

Jika saat uji coba muncul pesan butuh izin akses: Di Google Spreadsheet Anda → Ekstensi → Apps Script → Klik tombol biru Kelola Penerapan (Manage deployments) → Klik Ikon Pensil (Edit) → Pilih Versi Baru → Pastikan Siapa yang memiliki akses diubah menjadi "Siapa saja" (Anyone) → Klik Simpan / Terapkan.
